# ربات تلگرام X و Spotify

این ربات لینک‌های ویدئویی X/Twitter را مانند نسخه‌ی قبلی پردازش می‌کند و لینک‌های عمومی Spotify را نیز می‌پذیرد.

برای Spotify، ربات نام آهنگ و خواننده را استخراج می‌کند و فقط در منابعی جست‌وجو می‌کند که فایل قابل‌دانلود و مجوز عمومی/Creative Commons داشته باشند:

- Jamendo API (با `JAMENDO_CLIENT_ID`)
- Internet Archive Audio، فقط برای رکوردهایی با مجوز Creative Commons یا مالکیت عمومی

ربات برای جلوگیری از ارسال آهنگ اشتباه، عنوان و خواننده را امتیازدهی و تطبیق نزدیک می‌کند. در صورت یافتن فایل، منبع و لینک مجوز در کپشن تلگرام درج می‌شود. اگر نتیجه‌ی دقیق پیدا نشود، لینک رسمی Spotify برگردانده می‌شود. این پروژه از Spotify برای استخراج فایل صوتی استفاده نمی‌کند و منابع غیرمجاز یا دورزدن محدودیت Spotify را به کار نمی‌گیرد.

## اجرا

```bash
pip install -r requirements.txt
export BOT_TOKEN="توکن ربات تلگرام"
export JAMENDO_CLIENT_ID="شناسه اپلیکیشن Jamendo"
python bot.py
```

`JAMENDO_CLIENT_ID` برای Jamendo لازم است. جست‌وجوی Internet Archive بدون آن هم انجام می‌شود. سقف پیش‌فرض فایل ۵۰ مگابایت است و با `MAX_FILE_SIZE_MB` قابل تغییر است.

# ربات تلگرام X و Spotify

این ربات لینک‌های ویدئویی X/Twitter را مانند نسخه‌ی قبلی پردازش می‌کند و لینک‌های عمومی Spotify را نیز می‌پذیرد.

برای Spotify، ربات ابتدا اطلاعات عمومی لینک را از Spotify oEmbed می‌خواند و سپس فقط در کاتالوگ دارای مجوز Jamendo جست‌وجو می‌کند. اگر نسخه‌ی مجاز و قابل‌دانلود پیدا شود، فایل MP3 را در همان چت تلگرام ارسال می‌کند؛ در غیر این صورت نام آهنگ و لینک رسمی Spotify را برمی‌گرداند. این پروژه از Spotify برای استخراج فایل صوتی استفاده نمی‌کند.

## اجرا

```bash
pip install -r requirements.txt
export BOT_TOKEN="توکن ربات تلگرام"
export JAMENDO_CLIENT_ID="شناسه اپلیکیشن Jamendo"
python bot.py
```

`JAMENDO_CLIENT_ID` برای مسیر Spotify لازم است. بدون آن، قابلیت X کار می‌کند و برای Spotify فقط اطلاعات آهنگ و لینک رسمی نمایش داده می‌شود. سقف پیش‌فرض فایل ۵۰ مگابایت است و با `MAX_FILE_SIZE_MB` قابل تغییر است.
